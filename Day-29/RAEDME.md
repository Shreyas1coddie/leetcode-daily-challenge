## ✅ Problem Solved

### 1. Binary Tree Level Order Traversal (102)
- Approach: BFS (Queue)
- Time Complexity: O(n)
- Space Complexity: O(n)

---

## 💡 Approach Explanation

- Use a Queue to store nodes level by level  
- For each level:
  - Get current queue size  
  - Traverse all nodes of that level  
  - Add their children to queue  
- Store each level in a separate list  

---

## 📚 Key Learnings

- Difference between DFS and BFS  
- Level-wise traversal technique  
- Queue usage in tree problems  

---
