📌 Solved: **40. Combination Sum II**

Today I solved **Combination Sum II** using **Backtracking**.

🔹 Approach:

* Used recursion and backtracking to explore possible combinations.
* Sorted the candidates to handle duplicate values efficiently.
* Each element can be used **at most once**.
* Skipped duplicate elements at the same recursion level to avoid duplicate combinations.
* Added a combination when the remaining target became `0`.
* Backtracked by removing the selected element before exploring the next possibility.
