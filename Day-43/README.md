## ✅ Problem Solved

### 1. Search in a Binary Search Tree (700)
- Approach: DFS using BST property
- Time Complexity: O(h)
- Space Complexity: O(h)

---

## 💡 Approach Explanation

- If root is null → return null  
- If root value equals target → return node  

- If target < root:
  - Search in left subtree  

- Else:
  - Search in right subtree  

---

## 📚 Key Learnings

- Understanding BST property  
- Efficient searching using comparisons  
- Avoiding full traversal  

---

A simple and important problem to understand how Binary Search Trees optimize search operations.
