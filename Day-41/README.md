## ✅ Problem Solved

### 1. Invert Binary Tree (226)
- Approach: DFS (Recursion)
- Time Complexity: O(n)
- Space Complexity: O(h)

---

## 💡 Approach Explanation

- If node is null → return null  
- Swap left and right child  
- Recursively invert left and right subtrees  

---

## 📚 Key Learnings

- Tree manipulation using recursion  
- Importance of base case  
- Applying same logic to subtrees  

---

## 🚀 Notes

A fundamental tree problem that strengthens recursion and traversal concepts.
