## ✅ Problem Solved

### 1. Sum of Left Leaves (404)

- Approach: DFS (Recursion)
- Time Complexity: O(n)
- Space Complexity: O(h)

---

## 💡 Approach Explanation

- Traverse the binary tree using DFS.
- Check whether the current node's left child is a leaf.
- If it is a left leaf, add its value to the sum.
- Recursively traverse the left and right subtrees.

### 📌 A node is a left leaf if:

- It is the left child of its parent.
- It has no left or right children.
