## ✅ Problem Solved

### 1. Symmetric Tree (101)
- Approach: DFS (Recursion)
- Time Complexity: O(n)
- Space Complexity: O(n)

---

## 💡 Approach Explanation

- A tree is symmetric if:
  - Left subtree mirrors right subtree  

### 🔁 Recursive Check:
- If both nodes are null → true  
- If one is null → false  
- If values differ → false  

Then check:
- left.left vs right.right  
- left.right vs right.left  

---

## 📚 Key Learnings

- Mirror tree concept  
- Recursive pair comparison  
- Structural + value validation
