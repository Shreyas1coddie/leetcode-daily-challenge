## ✅ Problem Solved

### 1. Minimum Distance Between BST Nodes (783)
- Approach: Inorder Traversal (DFS)
- Time Complexity: O(n)
- Space Complexity: O(n)

---

## 💡 Approach Explanation

- Perform inorder traversal of BST  
- Store values in a list (sorted order)  
- Traverse the list and find minimum difference between adjacent elements  

---

## 📚 Key Learnings

- BST inorder → sorted output  
- Adjacent comparison for minimum difference  
- Tree traversal optimization
