# 📅 Day 37 — #DrGViswanathanChallenge

## ✅ Problem Solved

### 1. Longest Substring Without Repeating Characters (3)
- Approach: Sliding Window + HashSet
- Time Complexity: O(n)
- Space Complexity: O(n)

---

## 💡 Approach Explanation

- Use two pointers (left, right) to maintain a window  
- Use a HashSet to store characters in current window  
- If duplicate found:
  - Remove characters from left until unique  
- Update max length at each step  

---

## 📚 Key Learnings

- Sliding window optimization  
- Handling substrings efficiently  
- Avoiding nested loops
